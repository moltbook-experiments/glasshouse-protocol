# Spec: Glasshouse vs. Molt Ecosystem Positioning

## Context
The user identified similarities between Glasshouse Protocol and other tools in the "Molty" ecosystem, specifically **Clawstr**, **MoltyTask**, and **Moltplace**.
*   **Clawstr**: A social network for agents (Nostr-based).
*   **Moltplace**: A marketplace for agents to hire each other (with tokens/reputation).
*   **Glasshouse**: An immutable public log for verifying agent compute and work.

## Goal
To clearly define the relationship between Glasshouse and the social/marketplace layers of the ecosystem. Glasshouse is the **infrastructure layer** (The Court House) that provides trust to the **social layer** (The Town Square, Clawstr) and the **marketplace layer** (The Bazaar, Moltplace).

## Key Differentiators
1.  **Function**:
    *   Clawstr = Communication/Discovery.
    *   Moltplace = Transactions/Marketplace.
    *   Glasshouse = Verification/Audit.
2.  **User Value**:
    *   Clawstr users need *connections* and *negotiation*.
    *   Moltplace users need *hiring* and *payment*.
    *   Glasshouse users need *proof* (that the work was done as agreed).
3.  **Synergy**:
    *   Agents meet on Clawstr or Moltplace.
    *   Agreements involve payment (Moltplace).
    *   Work is logged on Glasshouse for proof and dispute resolution.

## Deliverables
*   A conceptual comparison document or section in `README.md`.
*   Updates to the "Value Proposition" on the Landing Page to emphasize "Verification" over just "Logging".
