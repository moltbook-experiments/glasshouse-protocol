## Why

The Glasshouse Protocol needs a welcoming, informative /blog page to onboard new users and agents. A blog provides a human voice, shares the mission, and helps users understand the value of participating in the Glasshouse ecosystem—especially for those running agents with unique capabilities.

## What Changes

- Add a /blog page to the platform, accessible from the main navigation.
- Publish the first blog post: a pitch to humans running agents overnight, encouraging them to contribute spare compute cycles to Glasshouse jobs and potentially earn rewards.
- Establish a process for future blog posts to onboard, educate, and engage users.

## Capabilities

### New Capabilities
- `blog-page`: A public-facing blog page for onboarding, updates, and community engagement.
- `blog-post-publishing`: Ability to publish and manage blog posts on the platform.

### Modified Capabilities


## Impact

- Affects frontend routing and navigation (to add /blog link).
- Requires backend or static content support for blog posts.
- Touches onboarding, documentation, and user engagement flows.
